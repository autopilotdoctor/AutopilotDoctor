Frequently Asked Questions

Does AutopilotDoctor send any tenant or device data to external servers?

Never. All WMI, registry, certificate, and log inspections execute 100% locally in memory. The only outbound connections are direct TCP 443 socket handshakes to Microsoft's public endpoints to verify firewall reachability, plus optional license key validation when activating Pro.

Can I run it during Windows Autopilot OOBE (Shift + F10)?

Yes. Run AutopilotDoctor.exe from a USB drive or network share inside the OOBE Command Prompt. Because Pro licenses cache a 30-day offline token locally, it works even when internet access is restricted or behind a proxy.

Does it modify registry keys or change system settings?

No. AutopilotDoctor is strictly read-only. It never alters registry values, certificates, or MDM enrollments automatically — it provides exact remediation commands so you stay in full control.
